# Claude Code project entry point

Follow [AGENTS.md](AGENTS.md) as the shared engineering instructions for this repository. Do not duplicate or override those standards here; Codex and other coding agents should use the same canonical rules.

For every implementation, classify the affected surfaces and follow [docs/qa/QUALITY_GATES.md](docs/qa/QUALITY_GATES.md). When the change affects UI, 3D presentation or opening framing, use [docs/qa/DEVICE_TEST_MATRIX.md](docs/qa/DEVICE_TEST_MATRIX.md).

Follow the appropriate detailed source: [UI Studio checks](docs/ui-redesign/IMPLEMENTATION.md), [figure runbook](docs/FIGURE_COLLECTION_RUNBOOK.md), [opening acceptance](docs/OPENING.md), and [operations/release](docs/OPERATIONS.md).

Keep checks proportionate to the change. Distinguish what was actually tested from what is pending; never claim Studio, device or publishing actions that did not occur. Do not publish a live place as part of a coding task without separate authorization.
