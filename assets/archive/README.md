# Superseded sources

`pocket_grove_corner_top_left_78396978639853.png` is the original first-upload source,
retained unchanged when the complete Collection production set replaced it. Its old
Roblox asset remains available, but the current manifest/mapping uses the newer artwork.
Nothing in this folder is uploaded automatically.

The `shop/` folder retains the two unused Shop emblem exports. The existing uploaded
Collection emblems remain the canonical Pocket Grove and Tidepool Tales identities, so
the alternate incoming emblems were archived rather than uploaded as duplicates.
