# Figure references

[The 190-figure catalog](blindbox_190_figure_catalog.md) is the source of truth for
collection membership, figure names and rarity assignments in this reference library.
Each collection has its own kebab-case folder; images use `<figure_snake>_<rarity>.png`.
Moonrace, Astral Signs and Pocket Orbit use their collection brand names as folder names.
All 190 references are present, including `seven-deadly-sins/demon_king_mythical.png`.
The catalog's statements that the Demon King reference is pending predate its addition.

Names marked `[verify name]` in the catalog remain provisional. In particular,
`japanese-yokai/rokurokubi_common.png` is the unmatched kimono girl and
`japanese-yokai/jorogumo_rare.png` is the unmatched orange fox spirit.
These two catalog assignments are tentative: the images do not clearly depict a
long-necked Rokurokubi or spider-like Jorogumo. The white-and-gold fox is assigned to
the catalog's Mythical Kitsune. Filenames retain the catalog names without extra suffixes.

This organization does not update the gameplay catalog, upload assets or publish a game version.
