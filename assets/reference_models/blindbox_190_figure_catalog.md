# Blind Box | 190 Figure Master Catalog

**Scope:** 190 planned figures in 21 collections: the previous 189 concept/reference designs plus newly added Demon King (reference sheet pending). This catalog does not imply 190 published Roblox models.

**Decision labels:** **Confirmed** = prior explicit rarity plan or repository record. **Proposed** = editorial suggestion for review. Names tagged **[verify name]** are provisional reconstructions and should be matched against the original generated sheets.

**Rarity order:** Common → Uncommon → Rare → Legendary → Mythical. No Epic tier.

**Owner-approved updates (October 14, 2026):** Greek Gods: Hades = Mythical; Zeus = Legendary. Mythical Creatures: Cerberus = Mythical; Dragon = Legendary. Seven Deadly Sins: Wrath = Legendary; added Demon King = Mythical (reference sheet pending).

**Owner-approved updates (October 15, 2026):** Applied image-ordered rarity lists for Western Zodiac, Biomes, Birthstones, Desserts, Five Senses, Greek Gods, Halloween, Human Emotions, Humanoid Chess Pieces, Chinese Zodiac, Planets, Seven Deadly Sins and Weather. All other placements unchanged. The catalog now has 143 confirmed and 47 proposed rarity assignments.

## Before adding to Roblox Catalog.luau

This roster is a **design-planning catalog**. Demon King is planned but has no generated reference sheet yet. Do not treat proposed rarities, unverified names, figure IDs, asset IDs, probabilities, or 3D upload status as production-approved. Approve the flagged choices first, then determine per-collection economy weights and integrate through the existing repository production pipeline.
