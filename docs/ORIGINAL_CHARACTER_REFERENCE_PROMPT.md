# Original Character Reference Sheet Prompt

Use this prompt to generate production-ready 2D character reference sheets for original blind-box figures. Designer-toy references such as Hirono are inspiration only and must not be copied.

---

CREATE PRODUCTION-READY ORIGINAL CHARACTER REFERENCE SHEETS FROM THE ATTACHED INSPIRATION IMAGES AND CHARACTER CONCEPTS.

These images will be used as the PRIMARY VISUAL SOURCE OF TRUTH by an AI 3D modeling agent that will recreate the final original characters in Blender and import them into Roblox.

The attached designer-toy references, including Hirono references if provided, are INSPIRATION ONLY.

DO NOT recreate, trace, reproduce, or make a near-copy of Hirono or any other existing collectible character.

The goal is to understand WHY the references work as premium designer toys, then create NEW characters with their own recognizable identities.

Accuracy, originality, consistency, geometric clarity, and usefulness for 3D modeling are more important than decorative presentation.

==================================================
PRIMARY OBJECTIVE
==================================================

Create ORIGINAL premium designer-toy characters inspired by the high-level design principles of the supplied references.

The final characters should capture qualities such as:

- premium collectible appeal
- emotional storytelling
- simple sculptural forms
- compact designer-toy proportions
- strong silhouettes
- restrained facial expressions
- appealing posture
- manufacturable geometry
- clean color relationships
- polished vinyl-figure presentation
- subtle personality
- high-end blind-box quality
- artistic emotional presence
- clear visual storytelling

However, the final designs must NOT reproduce the recognizable identity of any existing Hirono figure or other supplied reference character.

The references define:

- QUALITY
- DESIGN PHILOSOPHY
- LEVEL OF POLISH
- COLLECTIBLE APPEAL
- GENERAL EMOTIONAL TONE

They do NOT define the final character's exact appearance.

Do NOT create:

"Hirono with different hair."

Do NOT create something that could reasonably be mistaken for:

"an unreleased Hirono figure."

Instead, create completely new collectible characters that could exist in the same broad premium designer-toy market while remaining visually distinct.
